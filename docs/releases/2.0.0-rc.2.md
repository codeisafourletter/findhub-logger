# 2.0.0-rc.2 — private history application

This candidate turns collected rows into a usable local application: import → explore entities → understand collection freshness and gaps → export or clear. It replaces rc.1 as the proposed 2.0 candidate; stable is unchanged.

## Product outcome

- Responsive browser dashboard with synthetic demo, validated Sheet CSV / collector JSON imports, per-entity geographic plot and observation timeline.
- Latest collected timestamp and source displayed age shown separately. Adjustable stale/gap thresholds, address/name search, freshness filters, and actionable in-app stale alerts.
- Portable JSON export of all data, explicit demo provenance, atomic imports, duplicate removal, and clear/reload behavior.
- Local-only serving and tab-memory history; no remote maps, private data uploads, persisted browser history or notification delivery claims.
- Retains rc.1 offline doctor, encrypted-cache compatibility and sanitized collector failures.

## Try and migrate

Use Node 22, then `cd cloud`, `npm ci`, `npm run history`. Open http://127.0.0.1:4173. Choose Explore demo or import a private Sheet CSV. See [history guide](../history.md).

There is no database migration and no changes to collector credentials, Sheet schema or encrypted-cache format. Prior 1.0 raw diagnostic log scraping must migrate to fixed JSON failure codes as described in [rc.1 notes](2.0.0-rc.1.md). The new app groups by the collector's `person` field; it does not add device discovery. Import supports the existing fields and omits unknown columns.

## Acceptance and limits

Unit tests cover normalization, CSV parsing, schema rejection, export roundtrip, freshness/gap boundaries, synthetic fixture semantics and local server isolation. Browser acceptance covers demo → select/filter/search → JSON/CSV import → failed-import retention → export → clear/reload, mobile overflow, HTML injection treated as text, no persistent browser storage and no external requests. Existing authentication diagnostics tests still run.

No real Google session was refreshed and no live collection or Sheet access was performed. Authentication remains a separate operational blocker. The geographic view is an independently scaled coordinate plot rather than a navigation map. Gaps describe missing observations, not device outages. Alerts are local UI messages, not delivered notifications. Candidate only: no stable merge or production deployment.
